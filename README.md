# 🗺️ Mapa de Experiências

Uma aplicação web para registar locais visitados, avaliar experiências gastronómicas e partilhar esses momentos com amigos no mapa.

## 🚀 Tecnologias Utilizadas

* **Frontend:** SvelteKit, TypeScript, TailwindCSS
* **Mapa:** Leaflet (OpenStreetMap)
* **Backend:** SvelteKit API Routes
* **Base de Dados:** MySQL
* **ORM:** Prisma
